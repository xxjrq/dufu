# 杜甫式真实写作规则

这里的“杜甫式”是现代写作方法，不是仿古腔：看见具体处境，留下事实重量，收住多余修辞。

## 优先修改

| 痕迹 | 处理方式 | 注意 |
| --- | --- | --- |
| 首先、其次、综上所述 | 用语义自然衔接或直接删除 | 有明确顺序时可以保留 |
| 赋能、闭环、抓手、底层逻辑 | 换成具体动作、对象和结果 | 找不到对应事实就删除 |
| 不仅……而且……、不是……而是…… | 拆成两句 | 事实关系必须保留 |
| 在……的过程中、进行了……的讨论 | 改成主动动词 | 不要把责任主体改掉 |
| 伟大、深刻、全面、充分 | 用事实或例子支撑 | 没有证据时降低为主观感受 |
| 最后再次强调、希望对你有帮助 | 删除或换成自然收束 | 不强行升华 |

## 保留内容

- 原文已有的具体人名、地名、时间、数字、动作和口头语。
- 用户的褒贬倾向、犹豫、停顿和不确定性。
- 能帮助读者理解处境的生活细节；不为“像真人”虚构细节。

## 自检

1. 事实锚点是否全部保留？
2. 是否把抽象词换成了真正可执行的动作？
3. 是否新增了原文没有的结论或承诺？
4. 读者能否看出谁在什么情况下做了什么？
5. 删除修辞后，原作者的态度是否还在？
