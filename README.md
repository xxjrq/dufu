# 杜甫.Skill｜中文真实写作

把生硬、空泛、模板化的中文改成具体、克制、有生活质感的表达，同时保留事实、数字、专名和原始立场。

## 能做什么

- 中文去 AI 味和机器腔
- 自媒体、职场、产品介绍和日常文字润色
- 先诊断问题，或直接输出可用终稿
- 保留事实，不虚构细节，不承诺“检测必过”

免费、免登录、免 Key，支持 Codex、Claude、WorkBuddy、OpenCode 等能读取 `SKILL.md` 的 Agent。

## 最小使用

安装本目录后直接说：

> 使用杜甫 Skill，把这段文案改得更自然、具体、克制，保留数字和原意。

需要启发式诊断时：

```bash
python scripts/detect.py --file ./input.txt --json
```

## 边界

默认不写古文、不仿写杜甫诗句。这里的“杜甫”指真实、具体、克制的现代写作方法。医疗、法律、金融等内容只优化表达，事实仍需人工确认。
