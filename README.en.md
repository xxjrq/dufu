# Dufu

Rewrite stiff, vague, template-like Chinese into concrete, restrained prose with lived detail while preserving facts, numbers, proper names, and the author's intent.

It supports Chinese humanization, creator copy, workplace writing, product copy, diagnosis-only mode, and direct rewrites. It is free, requires no login or API key, and works with agents that can read `SKILL.md`.

The default mode does not write classical Chinese or imitate Du Fu poems. “Dufu” means concrete, grounded, and restrained modern writing. It does not guarantee AI-detector results and does not verify medical, legal, or financial facts.
